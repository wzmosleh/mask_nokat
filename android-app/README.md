# تطبيق Android

نفس تطبيق الويب (الملفات في جذر المستودع)، داخل تطبيق Android مبني بـ Capacitor.
الفرق مع نسخة الويب:

- التعرف على الصوت عبر خدمة Android، وإذن الميكروفون يُطلب مرة واحدة.
- الملف يُحفظ في الهاتف (`Documents/Massar`)، ثم يمكن **مشاركته عبر واتساب** (الملف نفسه).
- زر «رجوع» في الهاتف يرجع إلى الرئيسية.

## الحصول على التطبيق

يبني GitHub التطبيق تلقائيا بعد كل تحديث للفرع `main`، وينشره في صفحة **Releases** للمستودع
تحت اسم `mask-nokat.apk`.

## البناء يدويا

```bash
cd android-app
npm ci
npm run sync          # ينسخ ملفات الويب إلى المشروع
cd android && ./gradlew assembleDebug
```

يتطلب Node.js 22 وJava 21 وAndroid SDK.
