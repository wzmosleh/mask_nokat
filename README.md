# مسك النقط بالصوت

تطبيق ويب يفتح ملف النقط المحمَّل من **مسار**، وتُمسك فيه النقط بالصوت (الدارجة، الحسانية، العربية، الفرنسية، الإنجليزية)، ثم يعيد نفس الملف جاهزا للرفع إلى مسار. المواصفات الكاملة في [SPEC.md](SPEC.md).

## طريقة الاستعمال

1. افتح التطبيق في **Google Chrome** أو **Microsoft Edge**، مع اتصال بالإنترنت.
2. اختر ملف النقط المحمَّل من مسار (`.xlsx`).
3. اختر نوع المراقبة (الفرض الأول، الفرض الثاني، الأنشطة المندمجة…).
4. اختر طريقة ترتيب الأوراق: **مرتبة حسب اللائحة** أو **مبعثرة**.
5. اضغط «بدء المسك»، واسمح للمتصفح باستعمال الميكروفون، ثم تكلم:
   - **أوراق مرتبة:** قل النقطة فقط («طناش ونص»)، أو «غائب»، أو «لم أجد ورقته».
   - **أوراق مبعثرة:** قل الاسم ثم النقطة («سلمى العلوي طناش ونص»).
6. راجع النقط، ثم اضغط «تحميل الملف»: يُحمَّل الملف في مجلد التنزيلات، جاهزا للرفع إلى مسار.

## التشغيل

التطبيق ملفات ثابتة فقط (HTML وJavaScript)، بدون خادم ولا قاعدة بيانات. الميكروفون لا يعمل إلا عبر رابط `https://` أو على `localhost`:

- **على الإنترنت:** https://wzmosleh.github.io/mask_nokat/
- **على الحاسوب:** من داخل المجلد نفّذ `npx serve .` ثم افتح `http://localhost:3000`.

## الملفات

| الملف | الدور |
|---|---|
| `index.html`، `styles.css`، `app.js` | الواجهة ومنطق الإملاء |
| `i18n.js` | نصوص الواجهة بالعربية والفرنسية |
| `assets/logo.png` | شعار الوزارة |
| `parser.js` | فهم الجملة: الاسم، والنقطة بخمس لغات، والغياب، و«نعم/لا» |
| `massar.js` | قراءة ملف مسار والكتابة فيه دون المساس بالباقي |
| `vendor/jszip.min.js` | مكتبة JSZip 3.10.1 لفتح ملفات xlsx |
| `tests/` | الاختبارات، مع ملف مسار تجريبي بأسماء وهمية |

## الاختبارات

```bash
npm install
npm test                 # المحلّل وملف مسار
node tests/e2e.test.js   # المسار الكامل داخل Chromium (يتطلب Playwright)
node tests/mobile.test.js  # العرض على الهاتف
```

لا تضع ملفات مسار حقيقية في هذا المستودع: فيها أسماء تلاميذ قاصرين وأرقامهم.
